Este proyecto consiste en un sistema CRUD desarrollado en Java utilizando Programación Orientada a Objetos. 
Se implementó herencia mediante una clase padre llamada "Persona" y las clases hijas "Estudiante" y "Docente", 
permitiendo reutilizar atributos y métodos. Además, se utilizó ArrayList para almacenar dinámicamente los 
objetos registrados y realizar las operaciones CRUD. El programa 
también aplica encapsulamiento usamos encapsulamiento junto con getters y setters. Se implementó el manejo 
de excepciones con try y cathc y validaciones para controlar errores de entrada y asegurar que los datos ingresados por 
el usuario sean correctos.
